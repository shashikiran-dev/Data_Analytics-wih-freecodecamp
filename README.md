# Mean, Variance, and Standard Deviation Calculator

This project is part of the **freeCodeCamp – Data Analysis with Python** certification.

It calculates the **mean, variance, standard deviation, maximum, minimum, and sum** of the rows, columns, and all elements of a **3 × 3 matrix** using **NumPy**.

---

## 📌 Project Description

The function `calculate()`:
- Takes a list of **9 numerical values**
- Converts it into a **3 × 3 NumPy array**
- Computes statistical values across:
  - Columns
  - Rows
  - Flattened matrix
- Returns the results in a **dictionary format**

If the input list does not contain exactly 9 values, the function raises a `ValueError`.

---

## 🛠️ Technologies Used

- Python 3
- NumPy
